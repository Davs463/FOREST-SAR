## 3. Procesamiento reproducible
GCOV ruta típica `/science/LSAR/GCOV/grids/frequencyA/HVHV` (frequencyB si existe y ambos iguales), `mask`, `numberOfLooks`; comprobar grupos y atributos reales, no asumir que A siempre tiene HVHV. HVHV es intensidad real de canal HV, gamma0 corregida por terreno. No usar términos complejos como intensidad. Referencia https://hyp3-docs.asf.alaska.edu/nisar-docs/gcov/ . Comprobar unidad: potencia lineal positiva -> `10*np.log10(power)`; dB ya convertidos -> no reconvertir. Excluir fill, NaN, <=0 para potencia lineal, nodata. Máscara GCOV puede codificar información de conjunto de muestras; revisar semántica oficial y flags/version, no asumir `mask==0` universal, ni looks alto = probabilidad de acierto. Documentar reglas exactas de validez y mínimo looks si adoptado. Reproyectar/alinear en grid común y recortar AOI; interpolación continua sobre potencia lineal cuando apropiado y nearest para máscaras/categorías; evitar extrapolación. Calcular solo intersección de cobertura y calidad de ambas observaciones. Para área usar CRS proyectado apropiado y área de píxel por determinante afín / 10 000, no grados ni conteo de píxeles de mapa web. Si escala/CRS varía, reproyectar a grid métrico y documentar.

Diferencia `delta_db = db_final - db_inicial`. Umbral exploratorio T=3 dB, candidato disminución si `delta_db <= -T`, nunca `abs(delta)>3` como pérdida. Positivo = aumento de señal, no recuperación confirmada. Si existe máscara bosque base válida, limitar a esa población y publicar denominador. Si no existe, etiquetar cambio de radar, no bosque perdido. Filtro contiguo de área mínima opcional, registrar conectividad/umbral, no ocultar. No fijar un piso de ruido universal: si hay múltiples pares independientes y áreas estables justificadas, estimar distribución de cambios/ruido (mediana, MAD robusto o percentil) y validar; normalización por desplazamiento mediano solo si área estable representativa y prueba antes/después, conservar delta bruto; si no, offset=0, `noise_floor_db=null`, “no estimado”. No afirmar separación perfecta de ruido. Pendiente de campo, humedad, relieve, estacionalidad, geometría y saturación son factores alternativos.

Ejemplo de función numérica (prueba sintética, NO datos reales):
```python
import numpy as np

def delta_candidates(initial, final, mask_initial, mask_final, threshold_db=3.0):
    # inputs ya alineados, gamma0 lineal; masks booleanas de calidad derivadas de docs
    valid = (mask_initial & mask_final & np.isfinite(initial) & np.isfinite(final)
             & (initial > 0) & (final > 0))
    delta = np.full(initial.shape, np.nan, dtype=np.float64)
    delta[valid] = 10*np.log10(final[valid]) - 10*np.log10(initial[valid])
    candidate = valid & (delta <= -threshold_db)
    return delta, valid, candidate
```
Validar tamaños/CRS, umbral positivo finito, reglas máscara antes de llamar. Prueba: inicial=1, final=0.1 -> -10 dB, candidato; igual -> 0; NaN/no cobertura -> no válido. Arrays de pruebas en tests/fixtures nunca en web real.
